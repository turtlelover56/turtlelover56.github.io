# Anastasia Davis Portfolio

This repository hosts a personal portfolio site for Anastasia Davis, built with Next.js and Tailwind CSS. The site highlights her background as a recent computer science graduate, featured projects, experience, and links to her resume, GitHub, and LinkedIn.

## Features

- Responsive one-page portfolio layout
- Accessible, semantic content structure
- Downloadable resume PDF
- Links to featured GitHub repositories
- Clean, modern styling for a professional presentation

## Local development

Install dependencies and start the local server:

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Build

To create a production build:

```bash
npm run build
```

## GitHub Pages deployment

This project is configured for static export and deployment to GitHub Pages through GitHub Actions.

1. Push the repository to GitHub.
2. In the repository settings, enable GitHub Pages using the GitHub Actions workflow.
3. The workflow will build and publish the site automatically from the main branch.

The deployed site will be available at:

https://turtlelover56.github.io/
